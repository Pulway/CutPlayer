==================================================================
CutPlayer 使用手册
==================================================================

版本 0.1.1（Apple Silicon / macOS 14+）

一个为「看 LOG 灰片 + 套监看 LUT」工作流打造的本地视频播放器，同时具备完整的本地播放器功能。

------------------------------------------------------------------

一、这个软件的特点
---------

【1. 高规格素材的原生播放】
- 自研解码/渲染管线：FFmpeg 解码 → Metal 渲染（不走系统播放器那套，也不依赖 mpv 的视频输出）
- 支持 10bit / 4K / 高码率素材；实测 4K50 10bit 4:2:2 软解约 90fps
- 音频由 mpv 负责（纯音频时钟），画面与声音严格对齐

【2. 监看 LUT（核心功能）】
- 套用 LUT 后画面实时变化，适合看 LOG 灰片
- 自动记忆：文件级 + 目录级两套记忆，下次打开同一文件（或同目录文件）自动套上
- 批量套用：播放列表里 ⌘/⇧ 多选后一次设置
- LUT 库：常用 LUT 导入一次，之后从菜单一键套用
- 列表里每行右侧有 LUT 徽标，一眼看出哪些文件套了哪个 LUT

【3. 亮度曲线（特殊要求）】
- 修图风格的曲线编辑器，在 LUT 之后生效（先 LUT，再曲线）
- 曲线只影响预览画面——截图和导出绝不包含曲线，只带 LUT

【4. 截图与片段导出】
- 截图：16bit PNG，带 LUT、不带曲线，保存在 ~/Movies/CutPlayer/Screenshots
- 片段导出：按入点/出点导出，带 LUT、不带曲线，默认输出 MP4（H.265 10bit 4:2:2 硬件编码）
  - 访达里按空格就能预览，QuickTime 也能直接播
  - 硬件编码约 2.5 秒编码 1 秒 4K 素材（软编 x265 需约 14 秒）
- 导出结果可一键「在访达中显示」

【5. 输入色彩范围自动判定】
视频里的亮度有两种记法（limited 16–235 / full 0–255），猜错会导致画面发灰或死黑。
本软件会：
1. 先看素材标签；
2. 标签说是 full 时，再抽查实际像素判断标签是否可信（相机素材常有"标签撒谎"的情况）；
3. 你还可以在底栏用手动开关按文件覆盖它。

【6. 声画同步策略（seek / 换片不脱节）】
跳转或切换文件时，先按住音频，等目标画面解出来再一起开始 —— 不会出现"声音已经跑了几秒、画面还在慢慢追"。

【7. 极简自绘界面】
- 整片白色顶栏/底栏，无系统工具栏与分割线
- 顶栏/底栏自动隐藏（鼠标离开 2 秒），上下滑入滑出
- 点击视频标题即可收起/展开左侧播放列表（全屏下同样有效）
- 侧栏宽度可拖动调整，并且重启后仍然记得

【8. 内置自检】
打包命令可运行无头端到端自检：LUT 截图与 ffmpeg 参考的 PSNR、曲线只影响预览、导出区间与格式、无窗口保证等。

二、系统要求
------

  项目  要求
  --  ----------------------------------
  机型  Apple Silicon（arm64），不支持 Intel Mac
  系统  macOS 14.0 或更高
  磁盘  应用约 250 MB（内含 FFmpeg 与 mpv 依赖）

三、安装
----

1. 双击 CutPlayer-0.1.1-arm64.dmg，把 CutPlayer 拖进「应用程序」文件夹（DMG 里已放好快捷方式）。
2. 首次打开：本版本是本地构建、仅做临时签名，macOS 可能提示"无法验证开发者"。
   解决办法二选一：
   - 在「应用程序」里 右键点 CutPlayer → 打开 → 再点「打开」；
   - 或终端执行一次：
         xattr -dr com.apple.quarantine /Applications/CutPlayer.app
3. 卸载：把 App 拖到废纸篓即可。若想同时清除记忆数据，删除 ~/Library/Application Support/CutPlayer 文件夹。

五、按钮逐个说明
--------

【5.1 左侧「播放列表」】

头部三个按钮（右上角一列）

  按钮     图标        功能
  -----  --------  --------------------------------------------------------------------
  LUT    🎛 相机滤镜形   打开 LUT 面板：套用 LUT 库里的 LUT、导入新 LUT、从访达临时选一个、清除所选文件的 LUT。悬停会显示当前选中了几个文件
  打开文件   📁 文件夹     选择一个或多个视频加入列表（快捷键 ⌘O）
  打开文件夹  📁+ 文件夹加号  选择文件夹并递归扫描其中的视频，全部加入列表（快捷键 ⇧⌘O）

播放列表里的鼠标操作

  操作             效果
  -------------  --------------------------------------------------
  单击某一行（文字上也可以）  切换并打开该视频
  ⌘ 单击           加选 / 取消选中（不切换画面）
  ⇧ 单击           从上次点击处连续选中一段（不切换画面）
  点击列表下方空白处      清空选择（不影响正在播放的视频）
  按住拖动某一行        调整播放顺序
  右键某一行          菜单：播放 / 从访达选择 LUT… / 套用已导入的 LUT / 清除监看 LUT / 从列表移除
  把文件或文件夹拖进列表    直接加入（文件夹会递归扫描）

颜色约定：当前正在播放的那条是蓝底白字；其他被选中的是灰底；行尾的灰色胶囊是该文件已套用的 LUT 名称。

【5.2 视频「顶栏」】

  元素               说明
  ---------------  -------------------------------------------------
  文件标题             点击它可收起 / 展开左侧播放列表（侧栏收起时，标题会自动右移避开窗口左上角的红绿灯）
  时间 / 像素格式 / 分辨率  00:00:04.01 / 00:00:11.04  yuv422p10le  3840×2160
  蓝色 1.5×          当前播放速度不是 1× 时出现
  紫色「曲线」徽标         亮度曲线当前处于生效状态
  灰色胶囊             当前套用的 LUT 名称
  ⓘ                媒体信息（快捷键 ⌘I）

【5.3 视频「底栏」】

第一行：进度条

  元素    说明
  ----  -------------------------------
  左侧时间  当前播放位置（精确到 1/100 秒）
  滑块    拖动或点击跳转；松手才真正跳转（避免拖动过程中反复 seek）
  右侧时间  总时长

第二行：按钮（从左到右）

  按钮       图标                       功能
  -------  -----------------------  ------------------------------------------------------------
  上一个      ⏮                        播放列表里的上一条（快捷键 ⌘←）
  播放 / 暂停  ▶ / ⏸                    空格键也可以
  下一个      ⏭                        播放列表里的下一条（快捷键 ⌘→）
  播放模式     ➡︎ / ⏹ / 🔁               顺序播放：播完自动下一条；不连播：播完停在结尾；循环播放：播完从头再来
  IN       ⇤ IN                     标记入点（快捷键 [）
  OUT      ⇥ OUT                    标记出点（快捷键 ]）
  清除       ⊗ 清除                     清除入点/出点（快捷键 ⇧⌘X，没有设置时为灰色不可点）
  入出点显示    0:00:02.00 → 0:00:06.50  橙色文字，设置后出现
  截图       📷                        截图（带 LUT、不带曲线）保存到 ~/Movies/CutPlayer/Screenshots（快捷键 S 或 ⌘S）
  亮度曲线     波形图标                     打开曲线面板（快捷键 D 或 ⌘D）
  输入色彩范围   ◐ 半圆                     自动判定 / limited（16–235） / full（0–255），按文件记住。悬停可看到当前判定来源
  导出片段     ✂️                       打开导出面板（快捷键 E 或 ⌘E）
  速度       1× ▾                     0.5× / 0.75× / 1× / 1.25× / 1.5× / 2×
  静音       🔊 / 🔇                    快捷键 M
  音量       滑块                       0–150%（100% 为原始音量，可放大到 150%）
  全屏       ⤢ / ⤡                    进入/退出全屏（快捷键 F）。图标会随状态反向

六、亮度曲线面板（浮动窗口）
--------------

面板是独立浮动窗口，默认出现在主窗口旁边，不会盖住画面 —— 调曲线时能完整看到画面变化。

  控件        功能
  --------  --------------------------------------
  启用 开关     曲线是否生效（关掉后画面恢复 LUT 后的原样）
  预设 按钮组    正常 / 提亮 / 压暗 / 对比度 / 柔和对比 / 胶片感，点一下即套用
  重置        清空所有控制点，回到对角直线
  画布内操作     点击空白处 = 添加控制点；拖动控制点 = 调整；双击控制点 = 删除
  两个端点（橙色）  可上下拖动：抬黑场 / 压白场（X 固定在两端）；端点不可删除（防误删）
  关闭        关闭面板（Esc 亦可），曲线设置保留

面板底部会提示「曲线已应用到播放画面」。

> 记住：曲线只影响你看到的画面，截图和导出永远只带 LUT。

七、LUT 面板
--------

点左栏头部 🎛 按钮打开。

  区域 / 按钮        功能
  -------------  ---------------------------------------
  列表             已导入的 LUT；左侧 ✓ 表示当前正在生效的那一个
  列表行（单击）        把该 LUT 套用到当前选中的文件（没选文件时会提示先选）
  列表行（鼠标悬浮）      行尾出现红色垃圾桶；点击后需确认才会从库中移除（只移除记录，不删磁盘文件）
  导入 LUT…        从访达多选导入到 LUT 库（只入库、不套用）；同名 LUT 会自动跳过并提示
  从访达选择 LUT…     选一个 LUT 直接套用到所选文件（不入库）
  清除所选文件的监看 LUT  清掉所选文件的 LUT 记忆

八、导出面板
------

点底栏 ✂️ 打开。

  控件          说明
  ----------  ------------------------------------------
  入点 / 出点（秒）  可直接输入秒数；也支持 1:02.5、1:02:03.5 这类写法
  用当前入出点      把底栏标记的 IN/OUT 填进来
  画质预设        见下表，选中后下方会显示该预设的速度与用途提示
  输出到         默认保存到 ~/Movies/CutPlayer/Exports，可点「选择…」另存
  橙色提示        固定说明：导出内容 = 带监看 LUT，不含亮度曲线
  开始导出 / 取消   导出中显示百分比进度，可随时取消
  完成后         面板内直接显示「导出完成 + 在访达中显示」

【导出预设对照表】

  预设                          编码与规格                                    速度（4K）         适用
  --------------------------  ---------------------------------------  -------------  ---------------------
  H.265 10bit 4:2:2（硬件加速·推荐）  HEVC 4:2:2 10bit，约 70–100 Mbps，MP4/hvc1  约 2.5 秒 / 秒素材  日常交付，保留 4:2:2 与 10bit
  H.265 10bit 4:2:0（硬件）       HEVC 4:2:0 10bit，MP4/hvc1                约 2.9 秒 / 秒素材  体积更小
  H.265 10bit 4:2:2（x265 慢速）  HEVC 4:2:2 10bit，CRF 14                  约 14 秒 / 秒素材   画质/体积最优，导出时建议暂停播放
  H.264 8bit                  H.264 4:2:0 8bit                         快              发给别人，兼容性最好
  FFV1 无损                     FFV1 level 3（MKV）                        中              归档，体积很大

  内容         位置
  ---------  ----------------------------------------------------

十一、常见问题
-------

1. 画面发灰 / 黑不下去，或死黑、高光一片惨白？
这是输入色彩范围判定问题。点底栏的 ◐ 按钮：
- 发灰 → 选 limited；死黑 → 选 full。
- 也可以先用「自动判定」；悬停按钮能看到当前是"标签 limited / 像素抽查 / 手动"哪一种来源。
- 你的选择会按文件记住。

2. 为什么导出的片段和我调好的曲线不一样？
这是有意设计：曲线只是监看工具，不进入截图与导出。导出内容 = 原素材 + 监看 LUT。

3. 导出没有声音？
导出会带上原素材的音轨（有则带、无则无）。如果原文件本身没有音轨，导出自然也没有。

4. 拖动进度条时画面会短暂停一下？
这是声画同步策略：跳转时音频会等画面就位再一起播放，通常是 0.2–0.5 秒（取决于关键帧间隔）。这样不会出现"声音先跑、画面追赶"。

5. 4K 播放不够流畅？
- 4:2:2 10bit 这类素材只能用软件解码（系统硬解不支持），4K50 约 90fps，正常播放够用，但导出时同时播放会互相抢资源，建议导出时暂停播放。
- 若素材是 4:2:0 10bit，可优先用硬件编码预设导出以降低负载。

6. 首次打开提示"无法验证开发者"？
见「三、安装」第 2 步（右键 → 打开，或执行 xattr 命令）。

7. 关闭窗口就退出了？
是的，关掉主窗口即退出应用。数据（LUT 记忆、进度、侧栏宽度）都已保存，下次打开照旧。

------------------------------------------------------------------

十二、已知限制
-------

- 仅 macOS / Apple Silicon；Windows 版尚未开发（已有技术路线规划）。
- HDR / 杜比视界素材按 SDR 处理（暂不做色调映射），此类素材颜色会不正确。
- 4:2:0 素材的色度上采样算法与 ffmpeg 略有差异，彩色边缘极细微处可能有差异（肉眼通常不可见）。
- 暂无音频滤镜、字幕、硬件解码开关等高级选项。
- 应用为本地构建版本，未做 Apple 开发者签名与公证。

------------------------------------------------------------------

十三、快速上手（30 秒）
-------------

1. 把视频文件拖进左侧列表（或 ⌘O 选择文件）；
2. 单击列表里的条目开始播放；
3. 点左栏头部 🎛 → 导入 LUT… 把常用 LUT 加进库；
4. 选中一个或多个视频 → 点 🎛 → 点库里的 LUT 批量套用（之后打开这些文件会自动套上）；
5. 需要微调亮度时按 D 打开曲线面板（画面不被遮挡，随时对比）；
6. 按 S 截图、按 E 导出片段（都是带 LUT、不带曲线）。
